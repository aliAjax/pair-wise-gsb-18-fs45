# hxwl-04 术后冠部封闭与修复移交台

根管治疗完成后，按牙位登记暂封情况并判定走向：直接冠部修复，或转加固会诊。

## 技术栈

React + Vite + TypeScript + CSS（零新增依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 业务规则

- 牙位登记四项：暂封天数、剩余牙壁数、咬合痛、椅位时段
- **牙壁不足（< 2 壁）或暂封超期（> 14 天）只能转加固会诊，不能确认修复**
- 一个牙位只留一张待移交单；重复登记阻断并显示牙位与原值
- 一张椅位时段只排一颗牙；改约先释放原占用，新时段冲突时保持释放
- 修复确认后冻结冠部记录并释放椅位；复开必须填原因，旧值、原因与日期保留在修订链
- 刷新后自动校验牙位、椅位、暂封天数与修订链一致性，冲突提示携带牙位、牙壁数、时段与原值
- 状态持久化在 localStorage，提供“重置演示资料”

## 分层结构（资料 / 判定 / 页面分开）

```
src/
├── data/        资料层：类型、时间工具、椅位字典、演示种子、localStorage
│   ├── types.ts       数据结构与冲突 / 操作结果类型
│   ├── clock.ts       日期格式化
│   ├── reference.ts   咬合痛选项、椅位时段表
│   ├── seeds.ts       初始演示单据
│   └── storage.ts     读写 localStorage
├── domain/      判定层：纯函数，不依赖 React / DOM
│   └── rules.ts       资格判定、登记、改约、会诊、确认、复开、刷新一致性校验
├── ui/          页面层：展示与交互
│   ├── RegisterForm.tsx  牙位登记表（即时判定提示）
│   ├── ChairBoard.tsx    椅位台（一椅一牙、点槽改约）
│   ├── FormCard.tsx      待移交单与修订链
│   ├── RevisionChain.tsx 修订链时间线
│   ├── ConflictView.tsx  冲突台（牙位/牙壁数/时段/原值）
│   └── Metrics.tsx       指标卡
└── App.tsx      组装与状态调度
```
