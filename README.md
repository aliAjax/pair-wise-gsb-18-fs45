# hxwl-04 术后冠部封闭与修复移交台

根管治疗后，按牙位组织术后冠部封闭登记、椅位排程与修复确认移交。

## 技术栈

React + Vite + TypeScript + CSS（无新增依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 业务规则

- 牙位登记：暂封天数、剩余牙壁数、咬合痛、椅位时段。
- 牙壁不足（< 2 壁）或暂封超期（> 14 天）只能转加固会诊，不能确认修复；咬合痛只登记不阻断。
- 同一牙位只留一张未完结待移交单（待移交 / 加固会诊），重复登记被拦截。
- 椅位一个时段只排一颗牙；冲突提示携带牙位、牙壁数、时段和原值。
- 改约必须先释放占用，再排入新时段。
- 修复确认后冻结冠部记录（含确认日期与当时暂封天数）；复开时旧值、原因、日期追加进修订链，链只增不改。
- 状态写入 localStorage（键 `hxwl-04.coronal-handover.v1`），刷新与跨标签保持牙位、椅位、暂封和修订链一致。

## 分层结构

- 资料层 `src/data/`：领域类型、localStorage 读写与种子数据。
- 判定层 `src/domain/rules.ts`：纯函数规则（阈值、判定、冲突、所有状态变迁），不依赖 React / DOM。
- 页面层 `src/components/`、`src/App.tsx`、`src/state/`：展示与状态胶水。
